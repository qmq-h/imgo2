# 200Hz IMU与gyro噪声对照实跑

2026-10-21。用户请求检查其200Hz IMU配置，判断是否需要调整并验证。本轮只运行无界面Gazebo，没有连接真实电机/IMU，没有修改正式模型、Xacro、策略、增益或控制代码。

## 已完成

1. 核对实际启动链路：`gazebo.launch.py`接受`IMGO2_GAZEBO_URDF`；基准明确加载`imgo2_description/urdf/imgo2_real.gazebo.urdf`。该生成物IMU已200Hz，与用户粘贴一致；安装share为源码软链，不是旧副本。
2. 当前PPO YAML实查为12关节15/.5（不是此前20或历史25），base质量6kg；本轮不改这两项。两次都是当前53a57f909b61…权重、同一世界/可执行程序，前后变速0→+.5→0→−.5→0，vy/wz=0，每段10秒，初末零指令各5秒。
3. 基准保留gyro标准差.0002rad/s；临时对照只将三轴gyro标准差改为.005rad/s（25倍）。XML树归一化这三处后逐字节相同，确认其余模型字段未变。临时文件在/tmp，不增加模型副本到仓库。
4. 两次完成起身和50仿真秒PPO采集，没有触发60°倾斜停止条件；采集/控制器退出正常，本轮启动的进程均由脚本停止。脚本前后源文件哈希一致。基准和对照分别使用ROS domain76/77、Gazebo master11386/11387，均无GUI。
5. 首次受限环境不允许ROS/Gazebo本地套接字，未完成启动，已中断；随后在正常本机进程权限下两次实际完成。首次失败不计验证通过。

静站2–4秒三轴gyro标准差：基准约.000441/.000656/.002064rad/s，对照约.006521/.007067/.006324rad/s；输入噪声增加可见。这里含机身真实微动，不把输出标准差当成配置白噪声的精确估计。

**该200Hz配置可正常发布并供PPO使用；本次gyro白噪声对照没有复现用户描述的运动中剧烈振荡，但不是完全无影响。** 对照末尾零速度段出现低频摆动、停止后未像基准同样平稳；两组都有明显航向漂移，不能写作“整体部署无问题”。运动阶段统计量接近，单次/每组1次且未锁定物理随机种子，不能认定所有差异都由噪声造成，更不能推出实机IMU没有问题。

姿态仍是Gazebo Classic真值，不包含真实IMU融合、振动相关姿态误差与延迟。当前试验只评估gyro小白噪声，不覆盖它们。旧100Hz/25/.5图与本轮模型/增益均不同，不作为频率或噪声的唯一变量对照。

## 是否需要改正式设置

**200Hz可以保留。当前没有依据把正式gyro噪声改成.005或继续任意增大，更不应由此调真实IMU或PPO增益。** .005只是敏感性试验点，不是从真机标定得到的参数。accel噪声不直接进入当前PPO，增加它不会在此插件内自动改变投影重力。

待确认/待处理：

- 源生成一致性：`xacro/gazebo.xacro`的IMU仍100Hz，而实际real生成URDF为200Hz。直接重生成会恢复100Hz，也可能覆盖用户在生成物中改的质量等值。本轮故意未重生成/改Xacro；后续应将用户确认的模型参数同步回正确源，再有针对性生成和比对。根模型同步已有差异，不借本轮改物理参数。
- 先保留此基准，再分开测试有效小旋转姿态误差、IMU延迟与电机执行/反馈延迟。剩余实机振荡问题未修复；旧权重原训练配置、完整真实推理输入和动态时标仍待补齐。
- 当前15/.5与6kg的运动适用性、航向偏移及结束零指令摆动需重复/固定指令实验；单次无倒地不代表动态品质验收。

## 复现与证据边界

基准使用已有脚本，无控制参数改动：

```bash
python3 imgo2_deploy/ros2_ws/scripts/run_gazebo_ppo_ramp.py \
  --output /tmp/imgo2_imu200_baseline_new \
  --domain 76 --master-port 11386 --wall-timeout 150
```

需要本机正常ROS/Gazebo通信权限及该时刻模型/增益；输出目录改新名字，避免混入旧结果。对照准备方法：把生成URDF复制到/tmp，只修改`angular_velocity/{x,y,z}/noise/stddev`为.005；复制runner到/tmp，将其REPO固定为当前仓库根，并将两处`imgo2_description/urdf/imgo2_real.gazebo.urdf`字符串替换为该临时URDF绝对路径（同时影响加载与哈希记录）；以新domain77/master11387运行。正式工程文件不改；临时模型SHA256已在总结果记录。

两组分析使用已有`plot_gazebo_imu_ramp.py`，对原始CSV运行生成阶段统计/图。归档数据可gzip解压到临时目录，把明细JSON的`summary.metadata`写为`run_metadata.json`，再执行：

```bash
python3 imgo2_deploy/ros2_ws/scripts/plot_gazebo_imu_ramp.py \
  /tmp/恢复出的运行目录 --output-prefix /tmp/imu_replot
```

本轮验证范围是模型配置加载、实际IMU更新、短时PPO前后变速和gyro白噪声对照；未进行横移、主动yaw、真实硬件或延迟/姿态误差试验。
