# MuJoCo 两份 PPO 策略对照（2026-10-27）

## 结论

按用户最新说明，仅比较最新 `policy.pt` 与原来的 `policy_now.pt`；`policy_new.pt` 不作为结论依据。相同 MuJoCo 模型、PD、观测与动作接口下，最新策略确实呈现**更低的机身、更快的前进步态、前髋外展与后髋内收、运动时更强的机身摆动**。后退与原地转向跟踪更差；前进中高速跟速有改善。不能概括为所有指标都变差，也不能把全部差异归因于高度奖励。

两个后髋的目标角在静站及前进测试中始终达到动作裁剪边界：RL=-0.375 rad、RR=+0.375 rad，实际角约向内20°。这是当前策略输出经部署接口形成的持续内收，旧策略没有该现象。该数值是动作裁剪边界，不是模型关节限位。两份策略使用同一套关节映射，因此本轮没有出现必须通过调换关节或翻转轴符号解释差异的证据。

**静站剧烈抖动没有在这轮受控测试中复现**。最新策略静站姿态偏斜且更低，但稳态 roll/pitch 峰峰值只有0.085/0.119°；旧策略0.049/0.043°。实际GUI的切换瞬态、异步线程和墙钟调度尚不能据此排除。

## 方法和适用范围

- MuJoCo **3.2.7**，当前 `imgo2_description/mjcf/scene.xml` 平地与 `imgo2.xml` 机器人；模型、配置、权重均记录内容哈希。
- 新增独立无界面诊断程序，复用生产 `MujocoMotorPd`、`MujocoFeedback` 两个组件；逐物理步PD，配置P/D=25/0.5，默认角0/0.87/-1.82，髋动作缩放0.125、其余0.25，原始动作裁剪±3。按FL/FR/RL/RR逻辑关节逐项核对实际执行器。
- 物理步长0.5 ms；策略50 Hz；状态采集200 Hz；电机反馈附加延迟10 ms、IMU附加延迟0 ms，使用当前模型200 Hz IMU与0.005 rad/s gyro噪声，固定随机种子12345。日志读到的总帧年龄还包含采样/步进相位，不等于配置附加延迟。
- 45维输入依次为角速度×0.25、投影重力、速度指令、关节相对默认角、关节速度×0.05、上一拍裁剪动作；关节顺序与生产配置一致。
- 每组独立复位：固定默认站姿2秒，零指令PPO3秒，再施加指令20秒。统计剔除指令开始后前4秒，取后16秒。24组全部4000帧，无低机身/大倾角停止，生产文件前后哈希不变。
- 指令覆盖：静站、前进0.1/0.3/0.5/0.8 m/s、后退-0.3/-0.5 m/s、左右横移±0.3 m/s、原地转向±0.8 rad/s、前进0.4 m/s并左转0.8 rad/s。

这套程序使用固定仿真时间节拍；**没有运行GUI/FSM异步线程，也没有复现实际启动的完整状态切换**。本轮是相同部署物理与接口下的受控策略对照，不等价于验证生产可执行文件的所有时序。没有Gazebo/Isaac的同一批新策略A/B，没有训练或真机运行。

## 指标定义与诊断修复

- **高度**：base原点到水平地面的世界z，不是质心高度。
- **频率**：足端实际法向接触力5 N接触/2 N离地滞回、10 ms持续确认，去除20 ms以下接触抖动；完整离地段至少30 ms；同脚相邻落地周期取0.1–1.5 s范围，合并四脚取周期中位数。50 Hz是策略更新频率，与表中2–3 Hz的步态周期不同。
- **抬脚高度**：足端碰撞球底部距离地面的净空，每个完整摆动段取峰值再求均值；不是FOOT link原点或相对机身z。
- **外八/内八**：这里通过髋外展角（左q、右-q）与足端横向间距量化。关节是绕X的外展轴，不是脚尖的偏航轴，碰撞球也没有脚尖方向；图中连线只是平均足端位置示意。
- 初版诊断把 `mjOBJ_BODY` 的局部角速度当作机身轴，该局部坐标实际与主惯性轴有关，会把转向速度混入roll/pitch。已在**新增诊断程序**改用IMU site坐标，并重新运行最终24组；原生产反馈本就读取IMU site，没有改动。最终结果用Euler偏航微分关系独立核对，24组最大RMSE约0.0237 rad/s（5 ms差分离散误差）；初版三策略临时结果不用于本报告。

## 如何解释与下一步

同日进一步奖励审计已找到具体机制线索：对角髋镜像忽略左右外展符号，且8400后髋探索std达22.20/28.36，代表静站观测的原始Actor均值严重越过动作边界。原函数反例、实际checkpoint与训练日志证据见 [后髋饱和专项](../training/ppo_hip_saturation_reward_audit_2026-10-27.md)；没有据此宣称已证明单一训练根因或修复成功。

1. 相同模型与接口下换策略即可复现差异，因此当前最直接证据是最新策略在这套接口下形成了更蹲、前宽后窄的姿态；不是仅有GUI视觉错觉。模型/训练历史仍可能改变策略学到的行为，本轮不能证明新旧训练时用过完全相同的模型资产。
2. 最新训练保存的配置与部署在默认角、PD名义值、关节顺序、动作缩放和±3裁剪上相符，正式导出Actor也与checkpoint一致。没有证据支持通过改映射、扩大动作裁剪或翻转轴来修复本轮问题；两个后髋持续饱和应首先回到训练侧检查。
3. 当前rough源码base_height目标0.30、weight=-10；直接足高8 cm项weight=0；`feet_height_body`目标-0.20、weight=-5；`joint_mirror`=-1；独立髋偏离惩罚未启用。这些是待做受控消融的候选，**不是已证实的单一根因**。奖励语义问题及19项列表统一见 [rough复审](../training/ppo_rough_review_2026-10-26.md)，不在此重复展开。
4. 优先以原策略作为运动质量基线，修复/核对rough奖励语义，约束髋偏离与前后站宽，区分机身高度和足端摆动净空，再分别验收静站、正反低速、左右转向；不建议现在直接加大步高或取消动作限幅，也不能保证再训几千轮自行解决。

**已完成/已修复**：受控24组运行、可复现采集与统计工具、诊断角速度坐标错误修复并重跑、曲线与原始数据归档。**尚待修复/确认（PPO-GAIT-01）**：策略本身的低机身、髋内外收、方向不均衡、运动摆动；生产GUI切换/线程时序下的剧烈静站抖动；与Isaac同指令新策略对照及原策略确切训练来源。本轮没有改奖励/损失、模型、PD或生产控制代码。
