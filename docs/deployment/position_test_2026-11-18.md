## 行为与范围

源码：`imgo2_deploy/real/position_test_main.cpp`；构建：`imgo2_deploy/real/CMakeLists.txt`。

- 默认只预览；显式`--run`才连接电机。关节名为FL/FR/RL/RR与_hip/_thigh/_shank组合，对应当前四条总线各ID0/1/2。
- **硬件模式控制全部12轴**：保持各自启动逻辑位置，仅选中轴叠加正弦。沿用初始化自动归零，必须从配置规定的启动机械姿态开始，不能站起后重新启动归零。没有自动站起或切换姿态功能。
- 不运行PPO。q_des采用五次平滑包络正弦，dq_des=0、tau_ff=0；默认Kp25/Kd.8，全轴一致。没有新增上位机PD。
- 默认A=.01rad、f=1Hz、稳态10周期；开始保持1s、进入2s、退出2s、结束保持1s，总16s。参考函数按经过时间的20ms网格保持，主循环计划5ms提交；实际调度以记录为准，没有硬实时保证。
- 范围：0<A<=.05rad、.1<=f<=10Hz、周期1..30、ramp>=1s、hold>=.5s、总时长<=180s。增益在现有配置上限内。进一步限制连续参考速度保守界<=.5rad/s且不超过所选轴配置限值、加速度界<=10rad/s²；高频须减幅。这是参考函数的界，不是零阶保持指令的连续导数或硬件安全保证。
- 打开电机前检查全幅目标端点/增益，初始化后再按实际位置检查；拒绝靠Safety裁剪完成试验。
- 反馈年龄或主循环间隔>50ms、任意轴跟踪误差>.15rad、反馈速度绝对值>2rad/s、无效/错误反馈、stale/fault/clamped均停止。附加阈值尚未硬件验收，既有看门狗/健康检查保留。
- 正常完成、SIGINT/SIGTERM、故障及异常析构均通过原接口停机卸力。Ctrl+C不是平滑回位，支架须承载卸力后的机身。

## 构建与预览

### 默认运动顺序（11月19日补充）

以`--joint RR_shank`为例，只改变右后腿小腿关节的目标角度，其余11轴以相同PD保持初始化位置；不会自动站起、迈步或直行。硬件中心q0来自初始化后读到的逻辑位置，预览中心来自配置启动姿态。

| 相对时间 | 选中轴目标 |
|---|---|
| 0–1s | 保持q0 |
| 1–3s | 正弦运动幅度平滑从0增大到.01rad |
| 3–13s | 围绕q0以±.01rad、1Hz往复，稳态10周期 |
| 13–15s | 正弦幅度平滑缩至0，回到q0目标 |
| 15–16s | 保持q0，随后全部电机卸力、写日志 |

±.01rad约±.57°，目标峰峰值约1.15°；这是设定角，不保证反馈达到相同振幅。1Hz表示每秒一次完整往复。渐入/渐出也有正弦运动，所以`--cycles 10`计稳态周期，不是全程只摆10次。默认预览只把上述目标写CSV，完全不运动；显式`--run`才执行。

## 11月19日补充：完整首轮流程与整机对角步的边界

用户询问是否测单轴对整机的影响，或直接位控走对角步。首轮主要测“外部给定目标→关节反馈”，整机运动属于后续验证。固定机身会抑制横滚，所以首轮不能用机身不晃来验收止抖；腿自身惯量/重力及关节间耦合仍在。既有实机目标整机Gazebo回放已经完成，不将它列为未做过；新增单轴测试用于约束那些行走数据无法单独区分的参数。

完整顺序如下（方案，硬件未执行）：

1. 退出其它电机控制进程；机身由刚性支架承载并约束，脚离地且腿有运动余量，卸力后也由支架承载。恢复配置规定的启动机械姿态，再初始化；不能从站立姿态重启自动归零。记录姿态/固定点、温度和可取得的电压。
2. 按上文先预览RR_shank，25/.8，A=.01rad、.5Hz、8稳态周期。确认输入目标与范围后才由用户执行--run；该组22s，全部12轴有PD，只有选中轴目标变化，其余保持。CSV及console成对保存，结束后落盘。
3. 第一份先检查正常completed、有效反馈、新反馈时标/实际节拍、无夹限及异常；不通过时先处理停止原因。通过后同条件重复共3次，再分别做1Hz、2Hz各3次；每次启动前恢复相同机械姿态，输出用新文件名。
4. 原样目标及实际保持时序用于同固定条件Gazebo，初始姿态/几何/重力与约束一致；不能拿正常PPO自行目标作这次正弦的对照。当前位控CSV转换及固定条件回放入口仍未实现，已有自由机身PPO回放工具不能冒充此入口。
5. 逐频率给实仿q_des/q、dq、估算τ辅助时域图；稳态正弦幅值比、相位、平均静差、误差RMS及3次重复散布。使用真实时标，不移相消除待测差异；位控CSV同行q是在新目标提交前取得，不能当该目标即时响应。
6. 首轮筛选RR小腿与FR同型小腿，再补RR髋/大腿；这是代表轴筛选，不证明12轴一致。低频通过只覆盖.5–2Hz；机架和低频数据合格后再按余量减幅扩展至6–7Hz关心频带，及有明确几何/附件惯量的已知负载，并留另一输入/负载独立验证。高频幅值须另核对，不把低频参数直接照搬。

随后才研究单轴受载对整机的影响：保持明确的站立姿态/承重条件，小幅激励并同步记录机身IMU、全部关节和目标，观察关节响应如何转成横滚及支撑耦合。刚性固定台架与自由承重的约束不同，不能把两阶段的横滚幅值直接比较。当前程序没有IMU采集、站起/站立交接或自由承重测试模式；它只允许按上文固定机身脚离地使用，不能直接拿现有--run在自由站立机器上扫频。整机测试需要后续独立实现/验证，保持既有标定而非站起后重启归零。

## CSV时间语义

每tick12行、每行一个关节。预览模式反馈字段全空、ns时标为0，不伪造物理响应。

| 字段 | 含义 |
|---|---|
| mode/status | preview或hardware；最终结果preview/completed/interrupted/fault |
| t_s/reference_t_s/phase | 循环相对时间、20ms参考时间、开始保持/进入/稳态/退出/结束保持 |
| snapshot_ns | 主机取得状态快照后的steady_clock时刻 |
| submit_begin_ns/submit_end_ns | setTargets前后主机时刻，不是串口出线/设备应用确认 |
| command_seq | 本程序成功提交计数，不是设备回显序号 |
| joint/q_des/dq_des/tau_ff/kp/kd | 本拍提交的输出侧逻辑目标及增益，rad、rad/s、Nm |
| q/dq/tau_est/receive_ns | **本拍提交前读取**的反馈及驱动接收时刻；τ为电机估算值 |
| new_feedback | 接收时刻是否不同于上次记录该轴，不保证记录总线每帧 |
| valid/error/temp_c/clamped_count | 有效性、设备错误、温度及Safety累计裁剪次数 |

**同行q不是同行新目标执行后的反馈**，须用跨行时序分析；没有设备采样/应用时标和逐命令执行确认。日志保留原保持节拍，不移相消掉动态差异。

记录先存内存，卸力停机后才格式化/写CSV；状态/目标复制仍有分配开销，实际调度待测。SIGKILL、断电或严重崩溃可能丢失未写数据。故障触发时尚未提交的快照不计作成功提交行，具体停止原因在stderr，应保存终端输出。当前未实现旧Gazebo格式自动转换、自动幅相计算或已知负载装置。
