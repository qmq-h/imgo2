# 四足Sim2Real运动振荡：论文与排查路线

日期：2026-10-21。研究问题是Imgo2固定目标25/.5受载稳定、PPO零指令稳定、运动指令时可能明显振荡，部分托举减轻；增加Gazebo base质量/降低Kp未复现。以上由用户报告，本次不重复要求已完成的静态测试。

本轮已完成一手论文检索、阅读相关执行器/延迟/噪声与动作平滑段落，结合已归档日志提出区分性实验；未修改控制代码、宏、策略、训练参数或运行硬件/仿真。**没有定位唯一根因，也没有修复颤抖。**

## 1. 优先读的论文

### Tan等，RSS 2018

[Sim-to-Real: Learning Agile Locomotion For Quadruped Robots，原论文PDF](https://www.roboticsproceedings.org/rss14/p10.pdf)。优先读V-A Actuator Model / Latency和VI-B仿真到实机对照。

该文将执行器与延迟建模作为迁移的重要组成。它解释了仿真位置控制实现与真实PD可能不同，并用真实/仿真轨迹验证模型；观察延迟通过历史缓冲模拟。对Imgo2的启发是先核验动态响应和端到端时序，而不是仅匹配质量和增益。论文使用Minitaur/Bullet，其具体执行器结论不是当前Gazebo控制器的代码证明，也不能照搬其延迟数值或PD参数。

### Hwangbo等，Science Robotics 2019

[Learning Agile and Dynamic Motor Skills for Legged Robots，作者全文](https://arxiv.org/html/1901.08652)。优先读Modeling actuator dynamics与Control policy部分。

ANYmal工作用位置误差、速度历史学习关节执行器的动态力矩关系，并处理观测噪声，包括关节速度误差。对Imgo2的启发是“相同目标角、相同Kp/Kd”并不自动得到相同动态表现，dq反馈同样值得检查。ANYmal执行器与GO不同，不主张马上训练actuator network；先做有限幅、可控的动态响应验证，决定简单模型是否已足够。

### Mysore等，ICRA 2021

[Regularizing Action Policies for Smooth Control with Reinforcement Learning，CAPS作者项目页](https://cpslab.bu.edu/projects/caps/)；[论文](https://arxiv.org/abs/2012.06644)。

CAPS从训练目标约束动作的时间与状态邻域平滑性，用于缓解策略输出高频变化。该文实机示例包括四旋翼，不是此GO四足的验证。对Imgo2的启发是观测小扰动被动作放大时，后续可研究训练中的动作平滑/敏感度；部署端临时低通不等同于训练正则，且会引入延迟，不能直接当通用补丁。

### 后续可选：Kumar等，RSS 2021

[RMA: Rapid Motor Adaptation for Legged Robots](https://arxiv.org/abs/2107.04034)。主题是对载荷、地形等变化的在线适应。对当前调试的意义是负载和接触差异值得建模；不是必须先换RMA才能部署现有PPO。暂不建议以复杂算法替代接口和时序核验。

## 2. 目前如何判断关节反馈与IMU

**工程排查优先级：运动中的执行/反馈/接触闭环，其次并行检查动态IMU，保留策略敏感度与训练覆盖问题。** 这是基于现有证据的排序，不是论文替本机器人做出的诊断。

- 已有确切执行时序差异：主循环约200Hz、PPO约50Hz；7ms总线配置，末尾trace每关节外部请求/成功完成约140–141Hz、个别反馈间隔约32ms。不是200Hz上层读取就有200Hz独立关节采样；电机内部PD频率仍未知。频率差异并不自动等于不稳定，需看完整延迟、响应和策略裕度。
- 固定目标与零指令PPO都稳定，降低了“单纯支撑太软”“严重固定单位/映射错误”的优先级，未证明所有方向/动态输入正确。运动时目标变化、dq、足端接触、真实负载才充分激发闭环。
- 托举同时改变支撑力矩、接触约束和IMU振动，不能拿它单独区分关节与IMU。IMU测得抖动可能是准确记录真实运动，也可能通过融合误差/延迟参与放大。
- 关节问题不等于编码器损坏：正确但较旧/异步的q/dq、不同速度估计与滤波、实际PD和机械柔性都可能参与。应先验证动态链路，不直接更换传感器。
- 当前Gazebo IMU的姿态来自真值，gyro/accel噪声不等于真机融合姿态误差；实机gyro运动RMS也不等于噪声标准差。

已有依据见[频率核对](deployment_frequency_audit_2026-10-21.md)、[图与实机对照](ppo_sim_real_imu_comparison_2026-10-21.md)、[通信和诊断限制](go_imu_timing_vibration_review_2026-10-20.md)。

## 3. 后续工作顺序与判据（均未执行）

### A. 先修诊断记录，不改控制行为

保存推理线程真正使用的45维obs、previous_action、原始与转换后动作、输入采样时间/推理完成时间、控制提交时间；每关节实际接收时间/有效性，IMU sequence/接收时间与gyro/四元数，补accel用于分析。加入人工接触/托举事件标记。trace应停止写入或用正确同步后安全导出，不能直接拿并发ring快照做毫秒因果判断。

验收：输入与动作可离线逐帧复现；输出仅增加诊断字段，目标值与安全语义不变。日志写入需异步且记录丢帧，评估记录开销。当前policy.csv的重构obs不能替代该验收。此项待单独实施授权，本轮未改代码。

### B. 同一权重做仿真分组实验

固定基准模型、25/.5、命令和随机种子，先留无新增扰动基准。前后/横移/yaw分别测试，不把三种运动混在一个结论里。一次只开启一组：

| 组 | 单独加入的条件 | 可以支持的判断 |
|---|---|---|
| 执行时序 | 7ms外部目标刷新，按总线顺序/快照语义模拟状态更新，再单独扫命令/观测延迟及长尾 | 同形态振荡出现则支持时序敏感，仍需真实响应核对 |
| 关节观测 | q/dq偏差、速度噪声、状态年龄，逐项加入 | 策略是否容易被该关节通道扰动放大 |
| IMU | gyro扰动、有效的小旋转姿态误差、延迟分别加入 | 区分角速度与投影重力通道敏感度 |
| 接触/执行器 | 有测量依据的摩擦、力矩-速度/饱和、响应带宽等 | 解释负载/触地相关差异；不要只扫质量和Kp |

延迟扫描可用0/5/10/20ms作为**敏感性试验点**，不是已经测得的各链路独立延迟。7ms轮询、快照年龄、1.65ms事务是有关联的测量口径，不能全部机械相加，重复注入同一等待。先定义消息何时生成/应用/可见，再从时间戳复现。

验收：除“是否站住”外比较目标增量、角度跟踪误差、dq、gyro、姿态标准差、抖动主频、滑足和限幅/估算力矩。仿真复现支持机制相容，不是唯一归因。未复现也只排除该范围内模型，不能排除未建模误差。

### C. 受控动态执行器/IMU验证

不再重复固定姿态结论。后续如开展硬件实验，先在支撑、停止条件与既有限位下，使用受限的小幅平滑目标，比较sim/real的q_des、q、dq、跟踪幅值和相位；从低激励开始，出现振荡即停止，不开展无界扫频或直接重放整段行走动作。辨别电机动态跟踪在不运行PPO时是否已明显偏离。不能凭存在相位差就断言编码器错误。

IMU用已知方向的物理转动或有外部参考的测量核对轴/单位/姿态与gyro响应、时间一致性及受振动表现。仅做gyro与四元数的内部一致性不能证明绝对坐标正确；真实融合中四元数导数与gyro也不必逐点完全相等。无需在真机行走时将IMU或关节反馈清零来做消融。

### D. 再按证据调整

- 时序为主：降低桥接/调度长尾，验证有效更新；训练/仿真加入剩余延迟与抖动，保留原策略20ms语义。不是直接7ms改5ms。
- 关节动态为主：核对输出侧增益、速度反馈、限力矩和动态响应，在仿真同步实际模型后评估Kp/Kd。不能只在真机一口气25/.5改60/2。
- IMU为主：确认安装刚性/驱动时间、融合设置与实际滤波延迟，按测得偏置/噪声建模。加滤波需同时评估新增延迟。
- 动作敏感/高频目标为主：训练中评估action-rate/smoothness或CAPS类方法，检查步态/足端与跟踪性能。改变action_scale/部署滤波/输入裁剪都会改变策略工作条件，需sim2sim回归。
- 原权重训练来源未知：先补checkpoint与env配置；当前训练源码不是53a57f旧权重原配置的证明。RMA/新训练不是本轮首要操作。
