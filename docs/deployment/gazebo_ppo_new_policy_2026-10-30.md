## 5. 问题拆解

### 5.1 机身高度

- 新 policy：stand `.284`、walk `.237–.239`，**走起来低 4.5–4.7 cm**；target 是 .30，连站姿也只有 .28。
- policy_1：stand `.302`、walk `.288–.290`，**只低 1.2–1.3 cm**。
- 新 policy 的 stand 比 policy_1 低 1.8 cm，walk 低 5.1–5.3 cm。不是“走路才低”，而是**整体姿态本来就低，走起来再低一截**。
- 当前配置里 `feet_height_body=-1.5` 仍会把支撑脚往机身系 −.20 拉；`base_height=-12` 在 .238 时只扣 `−12×(.238−.30)²≈−.046/s`，不足以把机身拉高。`joint_pos_penalty=0` 又把“全腿回默认姿态”的刹车完全去掉，所以腿可以折叠/内收，机身就低。

### 5.2 髋关节

- 新 policy 行走时四髋**整体内收**：前后髋 outward 约 −3～−7°；MuJoCo +.3 前髋 −5.8°、后髋 −2.2°；−.3 后髋 −7.4°。按单腿看，FL/FR/RL/RR 是“左腿负、右腿正”的四髋内收（knock-knee/内八）。
- 同时髋有 **1.4–1.6° std、5–6° ptp** 的摆动；policy_1 只有 ~0.5° std、2° ptp，髋接近 0。
- `joint_deviation_l1=-0.2` 只选 hip，这个权重太弱，压不住 3–7° 的内收；`joint_mirror` 又把 hip 去掉，髋没有对角约束；`joint_pos_penalty=0` 也没有全腿姿态项。髋内收是“没有姿态约束 + 低机身/平衡策略”的共同结果。
- 内收可能帮助低机身下的横向稳定，但代价是站宽变窄、腿折叠、机身更低；视觉上就是“髋动得奇怪”。

### 5.3 步频/速度

- 新 policy +.3 是 1.61 Hz（Gazebo）/1.80 Hz（MuJoCo），+.5 是 1.96–1.98 Hz；policy_1 是 2.08–2.33 Hz。新策略确实更慢，符合“慢步”方向。
- 新 policy +.3 实际 .312、+.5 .499，跟踪不差；但代价是低机身 + 髋内收。
- +.2 仍然站着（MuJoCo），低速死区还在；Gazebo +.3 能走。

## 6. 优化建议（单变量）

### 第一刀：去掉 FHB 的向下拉力

```python
self.rewards.feet_height_body.weight = 0.0   # 或先 -0.5
```

从 `model_4999` 续 300–500 轮，LR 3e-4，看 stand/walk 高度和髋是否改善。当前 FHB 只有 −1.5，效果可能不大；但这是最干净的第一步。

### 第二刀：髋姿态约束（针对“髋奇怪”）

把 `joint_deviation_l1` 从 −0.2 提到 **−0.5 或 −1.0**（仍只选 hip）：

```python
self.rewards.joint_deviation_l1.weight = -0.5   # 先 -0.5，不够再 -1.0
self.rewards.joint_deviation_l1.params["asset_cfg"].joint_names = [".*_hip_joint"]
```

目标：把前后髋从 −3～−7° 拉回 ±3° 内，同时降低 1.4–1.6° 的摆动。若拉到 −1.0 后 roll/横向稳定性变差，改用 **髋角软区间**（只罚超过 ±3–5° 的部分），不要无限加大 L1。

### 第三刀：机身高度（如果前两刀还不够）

按顺序试，不要一起改：

1. `base_height_l2` 从 −12 提到 **−15**（不要直接 −20）；看 stand/walk 是否回到 .27–.29；
2. 加一个**小的全关节姿态项**：`joint_pos_penalty=-0.05～-0.1`（HIMLoco 用 −0.1），不要回到 −0.5；它能把腿从“折叠/内收”拉回默认姿态，但不会像 −0.5 那样强力压步幅；
3. 可选 `joint_pos_limits=-5` 作为软限位安全网，但它主要防极端，不负责 .30。

### 第四刀：如果髋仍内收/摆动

- 检查是否是**后髋**在 −.3 时内收（−7.4°）：后髋内收可能是后退时重心策略；用髋 L1 或软区间限制，配合 `feet_slide` 改世界系，减少“相对机身滑动”对支撑相的干扰。
- 如果髋 L1 加大后步频/速度变差，说明髋内收是它维持低机身/平衡的一部分；此时应优先把机身抬高（base/FHB/jpp），而不是单独锁髋。
