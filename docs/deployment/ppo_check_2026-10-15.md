## 输入和复用范围

默认12关节反馈取当前PPO YAML的 `default_dof_pos`，通过部署 `RobotAdapter` 排成硬件顺序：每条腿0/0.87/−1.82 rad；dq=0、速度指令=[0,0,0]。IMU默认RPY=[0,0,0]度，生成wxyz=[1,0,0,0]与gyro=[0,0,0]。RPY零姿态对应正常单位四元数，不能把四元数四项都置零。

唯一自定义的数据源是测试文件中的 `feedback()`：生成部署使用的 `HardwareState`，填入关节、IMU数据、有效性和steady clock接收时间；没有串口设备对象。

后续实际调用部署现有接口：

```text
模拟HardwareState
  → RobotAdapter::toPolicy
  → InferenceWorker（部署control_ms更新快照、policy_ms异步推理）
  → PolicyRunner::infer
      → buildObservation（gyro、投影重力、commands、q-default、dq、last_action）
      → 已有TorchScript模型
      → clipActions
      → convertAction（default_dof_pos + action_scale * action）
  → RobotAdapter::toHardware
  → Safety::clamp（在副本上检查，给面板显示限幅状态）
  → 原TerminalDisplay防滚屏
```

使用同一 `PolicyConfig`、`DeploymentConfig`、CPU预热、最新结果快照及推理异常/过期检查；last_action由原PolicyRunner持续维护，不在每帧清零。可执行文件资源定位也提取为公共 `apps/deployment_paths.h`，部署主程序和检测工具共用。

本工具直接检测PPO数据链路，无需输入0/1，不执行站起FSM或真实硬件初始化、目标发送。`mapping_confirmed=false`也可离线观察；真实部署的PPO锁仍保留。使用deployment中实际配置的排列，未暗中覆盖成另一个映射。

**关节反馈始终固定在站姿，策略输出不回填为反馈。** 因为last_action随推理更新，即使RPY保持零，前几次输出也可能变化；结果不表示机器人一定会稳定站立，不能代替闭环仿真或实机验证。

## 编译运行

从仓库根目录执行；LibTorch路径为本机已有位置，其他机器应替换为实际依赖路径：

```bash
cmake -S imgo2_deploy/go_imu -B /tmp/imgo2_rl_deploy \
  -DCMAKE_BUILD_TYPE=Release -DGO_IMU_BUILD_RL=ON \
  -DCMAKE_PREFIX_PATH="$PWD/imgo2_deploy/library/inference_runtime/libtorch"
cmake --build /tmp/imgo2_rl_deploy --target ppo_check -j2

# 全部默认：站姿反馈、RPY零、gyro零、速度命令零；Ctrl+C退出
/tmp/imgo2_rl_deploy/ppo_check

# 固定roll=3°、pitch=-2°、yaw=0°
/tmp/imgo2_rl_deploy/ppo_check --rpy 3 -2 0

# roll ±2°、pitch ±1°，0.2Hz正弦浮动，yaw不动
/tmp/imgo2_rl_deploy/ppo_check --amplitude 2 1 0 --frequency 0.2

# 围绕指定姿态浮动，10秒后退出
/tmp/imgo2_rl_deploy/ppo_check --rpy 3 -2 0 --amplitude 1 1 0 --frequency 0.2 --duration 10
```

可用 `--policy-dir` 指定包含ppo目录的根路径，`--config`指定deployment.yaml；默认读取可执行文件旁的policy和config。CMake单独构建ppo_check也会复制资源，install包含该工具。缺模型时参照部署指南中模型搬运与SHA256说明。

`--rpy`与`--amplitude`均按roll/pitch/yaw顺序、单位度；`--frequency`单位Hz（0～10），默认0.2；`--duration`单位秒，0表示持续运行。RPY各轴基值绝对值加振幅绝对值不超过180°，参数必须有限。

浮动使用 `rpy=base+amplitude*sin(2πft)`，从RPY生成body→world四元数，同时把RPY导数转换为机身角速度；不会出现姿态一直变化、gyro却固定为零的假反馈。固定倾角时gyro为零。IMU到投影重力的转换仍走部署数学接口。

```text
Scaled target(rad)       Hip       Thigh       Shank
FL               -0.015272   0.885584  -1.694945
FR                0.049783   0.866870  -1.628972
BL               -0.062984   0.947945  -1.470103
BR                0.044912   0.905615  -1.652769
```

以上为本机默认零姿态第20次推理的一次输出示例，不是固定期望目标。标题处显示当前模拟RPY、推理seq、结果年龄，以及 `Motor limit: OK/CLAMP`。CLAMP说明真实Motor安全层会进一步裁剪；不会把这次裁剪伪装成原策略输出。无首结果时角度显示 `--`。

刷新200ms，推理沿用部署默认20ms，显示刷新不决定推理频率。TTY使用原备用屏幕、光标隐藏/恢复、固定位置刷新；窄终端提示扩窗，避免折行滚屏；输出重定向时不写ANSI控制码。Ctrl+C/SIGTERM退出恢复光标。
