## 2. 物理约定（与计划逐条对应）

```text
d  = ||p_L - p_R||          机器人后挂点 p_R、小车挂点 p_L（世界系）
δ  = d - L0
T  = 0                      δ ≤ 0        （松弛：绳只能拉、不能推）
   = max(0, k·δ + c·ḋ)      δ > 0        （张紧）
e  = (p_L - p_R) / d
F_R = +T·e                  施加到机器人后挂点
F_L = -T·e                  施加到小车挂点
```

- **伸展率取挂点速度**：`ḋ = e·(v_L - v_R)`，其中 `v` 必须是**挂点**速度。刚体上某点速度
  为 `v_com + ω×offset`，模块提供 `point_velocity()` 补这一项 —— 直接用质心速度会漏掉 ω×r。
- **力对由构造保证等大反向**（`F_L = -F_R`），所以绳力是内力：整体动量精确守恒（测试）。
- **力臂**：`cart.urdf` 的 `rope_attachment` 是无质量帧（`base_link` 下 `xyz="0.25 0 0"`、无旋转），
  Isaac Lab 导入时会把它合并进 `base_link`（实测警告 `link rope_attachment has no body properties
  ... merged into base_link`）。因此不能依赖它作为独立 body 存在：力要施加到 `base_link`，
  并用 `offset_torque(force, offset)` 补上 `offset × force` 的力矩（架构记录 §3 的要求）。
  offset 需由调用方把本体坐标系的挂点偏移用 `isaaclab.utils.math.quat_apply` 旋到世界系后传入，
  本模块不重复实现四元数数学。
- **参数校验**：k 必须有限且为正，c 必须有限且非负，L0 必须有限且非负；标量几何量还要求
  非负/有限；两个挂点重合（d = 0）时标量入参直接报错。张量入参的非有限值仍由调用方在写入
  仿真缓冲前检查（`scripts/towing/cart_coast.py` 已有同类检查）。
- **接口约定**：与同目录 `resistance.py` 一致 —— Python 数、numpy 数组、torch 张量都能用。
  实现上只用算术（`max(v,0)` 写成 `(v+|v|)/2`、范数用 `(Σvᵢ²)**0.5`），**没有任何后端分支**，
  因此在没有 GPU 的机器上可直接复现。

## 3. 离线验证

解释器 `/opt/conda/envs/isaaclab/bin/python3`（Python 3.11.13），从 `imgo2_rl/tests` 执行。

| 验证 | 结果 |
|---|---|
| `python3 -m unittest test_towing_rope` | **31 项通过** |
| 全量离线测试（9 个测试文件） | **142 项通过**（本轮之前是 111 项） |
| `check_model_sync.py` / `check_asset_paths.py` / `check_cart_model.py` | 退出码均为 0 |
| `git ls-files -i -c --exclude-standard` | 为空 |

覆盖的判据：

- **松弛**：δ ≤ 0 时 T 恒为 0，且与 ḋ 的正负无关；**刚好绷直（δ = 0）而 ḋ > 0 时仍为 0**
  —— 计划定义的不连续点就在 δ = 0，测试显式锁定这一边界。
- **张紧**：T = kδ + cḋ；ḋ 大幅为负导致 `kδ + cḋ < 0` 时被单侧约束截到 0（绳不能推）。
- **几何**：方向为单位向量且由机器人指向小车；力的模等于张力；`ḋ` 等于相对速度在绳方向的投影
  （横向速度不贡献）。
- **力臂/速度**：`offset_torque` 与手算叉乘一致、平行时为零；`point_velocity` 正确补 ω×r。
- **不变量（双质点数值积分，dt = 1e-4、20000 步）**：总动量守恒到 1e-9（相对）；
  `δ ≤ 0 ⇒ T = 0` 零违反；总机械能（动能 + 弹性势能）不增且末态确实下降；**松弛段动能逐帧
  漂移恰为 0**（不做功）。
- **后端一致性**：同一组输入在 numpy（含批量数组）与 torch 上给出的张力/力与标量一致
  （torch 按默认 float32 给容差）。
- **包契约**：`rope.py` / `resistance.py` 的 import 集合 ⊆ {`__future__`, `math`, `typing`}；
  在子进程里按路径构造合成包导入 `mdp`，断言导出齐全且未引入 torch / numpy / isaaclab / omni。
  （不能直接 `import imgo2_rl.tasks...`：父包 `tasks/__init__.py` 会 import isaaclab，在离线
  环境里断在 `isaaclab.utils.math → import omni.log`，这是仓库既有环境限制。）

## 4. 离线过程中发现的两条模型性质（重要）

### 4.1 「张紧」不能用 δ > 0 判断，只有单向蕴含成立

`δ ≤ 0 ⇒ T = 0` 恒成立；但 **`δ > 0 ⇒ T > 0` 不成立**：δ > 0 且快速接近时 `kδ + cḋ` 变负，
被 `max(0, ·)` 截断成 0。实测在 20000 步里命中 **250 步**。所以后续 Logger（P5）与判据里
判断「绳是否在拉」应当**以 T > 0 为准**，不要用 `d > L0`。

### 4.2 单侧绳在无外力双质点模型里**不会**收敛到同速

松弛段不做功 ⇒ 相对速度被**冻结**。因此欠阻尼下的动量交换过冲不会被纠正：一旦绳松掉，
两体就按当时的相对速度自由漂移，直到几何上再次绷直才发生下一次交换。实测（机器人 5.53 kg
在前、小车 10 kg 在后，v_R 初值 0.5 m/s，L0 = 1 m、k = 4000 N·m⁻¹，积分 4 s）：

| c | ζ | 末态相对速度 v_L − v_R | 松弛步占比 |
|---|---|---|---|
| 100 | 0.42 | −0.359 m/s | 97.0% |
| 240 | 1.01 | −0.085 m/s | 97.6% |
| 400 | 1.68 | +0.434 m/s | 99.2% |

即存在持续的 slack ↔ taut 循环，**提高阻尼并不能让它收敛**（ζ ≈ 1 最好但也只剩 −0.085 m/s）。

**这条不能外推到 P4**：该模型里机器人是自由质点，而 P4 的机器人由冻结的 locomotion 策略
驱动、是带有限权限的速度源。结论只说明「绳参数与判据必须在真实系统里重新评估」，也正是
计划 P4 要求的检查项（`v_R ≈ v_L`、`T(t)` 是否进入相对稳定区间）。已按此写成待验证项。

## 5. 参数选择的工程起点（**未标定，待 P4 复核**）

计划没有给 k / c 的数值，这里只记录量级依据，不作为已验证取值：

- **k** 决定绷直后的振荡时间尺度 `ω = sqrt(k/m_eff)`，`m_eff = m_R·m_L/(m_R+m_L)`
  （5.53 kg 与 10 kg ⇒ 3.56 kg）。`k = 4000 N/m` 时 ω ≈ 33.5 rad/s，dt = 0.005 s 下
  ω·dt ≈ 0.17，显式积分安全；`k = 1e5` 时 ω·dt ≈ 0.85，已接近显式积分稳定边界，必须像
  P2 那样做 dt 减半复核。
- **稳态伸长** `δ_ss = T/k` 应远小于 1–2 m 的停止距离：`k = 4000` 时预期 T ≈ 10–50 N
  对应 δ ≈ 2.5–12.5 mm。
- **c** 的临界值是 `2·m_eff·ω`（k = 4000 时 ≈ 239），但见 §4.2：临界阻尼只保证单次张紧
  过程不过冲，不保证整体收敛。
