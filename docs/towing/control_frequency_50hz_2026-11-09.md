# 上下层控制统一为 50 Hz

用户决定将上层策略与冻结底层策略统一为 50 Hz。基于远端 `9e6e6e4`，保留四档坡道、80 列与 1600 环境。

已修改训练配置 `upper_control_dt=0.02`、环境 `decimation=4`、动作项默认周期，以及回放脚本默认周期和频率说明。物理步仍为 0.005 s，两层每四个物理步依次更新：先上层动作，再底层推理，再叠加残差。未修改模型结构、奖励权重、观测缩放或物理参数。
