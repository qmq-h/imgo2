- **run**：`imgo2_rl/logs/towing/play_test/20261009T122044Z_b258d30d`（`state=completed`、800/800、
  `no_cart_fraction=0.125`、`--record-every 5`、`--write-csv all`、`elapsed_s = 1468`）
- 用法：`python3 imgo2_rl/scripts/tools/play_test_stats.py imgo2_rl/logs/towing/play_test/20261009T122044Z_b258d30d --segments --segments-limit 0`
- 口径：`q*` = 当拍下发的关节目标（`default_dof_pos + action_scale ⊙ clip(a, ±3)`）；
  误差 = `q − q*`（12 关节池化）；**静差** = 12 关节的 `|mean(e)|` 平均，**动态** = 其 std 平均；
  `|vx−cmd|` = 体系 x 速度与指令之差；段按 `robot_progress_m` 落在剖面 2.25/5.25/6.0/9.0 m 的位置切。

## 4. 结论（本轮数据支持的）

1. **`q − q*` 主要不是拖曳造成的**：无负载时池化 RMS 已经是 0.171–0.206 rad，拖曳只增加
   **+0.003 … +0.054 rad**；其中**静差部分（扛体重的 PD 顺从性）几乎不变**（Δ 0.001–0.018）。
2. **拖曳的代价集中在「跟速」与「追尾」**：`Δ|vx−cmd|` 达 **+0.08 … +0.32 m/s**（无负载 0.02–0.10，
   拖曳 0.16–0.40），且**上坡与坡顶最大**（10° 上坡 +0.324、5° 坡顶 +0.274）；
   判定码上，无负载 **COL 0 / SPD 0**，拖曳 **COL 39% / SPD 18%**。
3. **`JNT` 两边都 100%** ⇒ 它测的是"PD 静差 vs 未标定阈值"，不能当验收判据（要么按无负载基线做
   相对判据，要么按实测分布重标阈值）；真正有区分度的是 **跟速** 与 **追尾**。
4. 差值的坡度依赖：**5° 坡顶 +0.054 / 10° 坡顶 +0.046 / 5° 上坡 +0.029** 最明显 ——
   与"上坡需要额外推力、坡顶附近最吃力"一致。

## 5. 已知的口径瑕疵（不影响上表）

- `_nocart` env 的**小车运动类字段**（`cart_coast_distance_m` / `cart_coast_to_rest_m` /
  `cart_speed_at_stop_mps`）仍然照算，但小车被停在 2 m 外、绳力为 0 ⇒ 这些数**没有意义**
  （判定已中性化：无负载 env 不产出 COL/LOW）。要清掉的话就在 `compute_case_metrics` 里
  一并置 None（下一轮改）。
- 拖曳段的「平地(出口)」段在两轮里都没有样本（5 s 内只有最快的档接近 9 m），需要更长
  `--tow-duration`（如 8–10 s）才会出现。
