# model_1500 上层策略评测结论（2026-11-11，20 Hz 训练）

> 上层：`2026-11-09_22-22-33_smoke_70col_oldppo/model_1500.pt`（contract v6，训练时
> **upper_control_dt=0.05 s / 20 Hz**）；低层：部署侧老 PPO `53a57f90…`；上层关闭
> 噪声、确定性均值。地形 70 列 × 20 行 = 1400 env（平地 / 5° / 10° / 15° / 减速带 / 波浪）。
> 两组：无负载（`--no-cart-fraction 1.0`）与 5–30 kg 有负载（六档等概率）。

## 1. 无负载：1400/1400 通过

- 旧口径 **1400/1400 OK**，0 FALL；15° 稳态速度比 1.07。
- 相比老 PPO 无载基线（70 列子集约 826/1400，15° 0/200、20° 0/200），上层把无载
  15° 的速度与稳定性补上了；20° 已删除，不再评价。

## 2. 有负载：速度明显改善，但侧翻显著增加

## 3. 为什么训练 fall 1.8%、测试 FALL 7.1%？

两者不是同一统计口径：

1. **质量分布不同**：训练是连续 `mass_range=(5,30)`，25–30 kg 只占约 20%，30 kg 端点
   几乎采不到；测试是 5/10/15/20/25/30 **六档等概率**，25 kg 和 30 kg 各 1/6。
   而 25 kg 翻车率 18.9%，会把聚合值拉高。
2. **训练有 12.5% 无小车锚点**，测试 loaded 组全部带车；训练 fall 率分母更大。
3. **训练采样带噪声，测试用确定性均值**；确定性动作在 15°/25 kg 边界状态不一定更稳。
4. 训练日志的 1.8% 是**回合终止比例**（time_out 97.8%），测试 7.1% 是**逐 case 的 FALL 比例**；
   两者定义、分母、质量分布都不同。
5. 即使只和老 PPO 基线比，upper1500 也从 2.6% 升到 7.1%，说明上层在重载 15° 的姿态
   控制确实有实质退化，不能全部归因于口径。

## 4. 结论与下一步

- **无载**：upper1500 可用；15° 也能稳定通过。
- **带载**：速度/停车提升明显，但 15°/10° 侧翻显著增加，25 kg 最严重；当前版本不能作为
  重载安全策略验收。
- 任务 0/1400 仍由 JNT 主导，但即使排除 JNT，FALL 本身也不合格。
- 2026-11-09 远端已把上层与低层统一到 **50 Hz**（`upper_control_dt=0.02`、`decimation=4`）。
  `model_1500` 是 **20 Hz** 训练的，不能直接用于 50 Hz；需要按 50 Hz **从零重训**。
- 50 Hz 新策略训练后，建议先做：
  1. 同一 upper 的 **20 Hz vs 50 Hz** 对照；
  2. 同一 upper 的 **老 PPO vs PPO@2500** 低层 A/B；
  3. 重点看 **25 kg / 15° / 1.0 m/s** 的 rollover。
