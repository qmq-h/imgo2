## 1. 0 kg 无载（无小车锚点）

SPD 674、FALL 100。

| 地形 | 旧口径 OK | 现象 |

| 5° | 100/200 | 一半速度跟踪失败 |

| 15° | 0/200 | **能爬**（稳态速度比 1.07/1.19），但 MAE/std 超限，全部 SPD，无翻车 |

结论：**15° 无载能爬但速度不稳；20° 无载爬不上去，1.0 m/s 会翻。** 20° 已按用户要求删除。

## 3. 结论

1. 老 PPO 的可用域主要是**平地/减速带/无载 10–15°**；带载后速度跟踪全面不足。
2. **15° 是新的最高平滑坡，也是带载最危险的翻车地形**：1.0 m/s、10–20 kg 有 29 次 rollover。
3. **10° 的瓶颈是牵引力**：25/30 kg 停滞而不是翻车。
4. **20° 已删除**；此前“20° 带载不翻车”只是因为它爬不上去/停滞，不代表能通过。
5. 老 PPO 作为低层训练起点时，不能指望上层残差修好 15° 牵引力；应先关注低层在 15° 的速度/力矩余量。

## 4. 限制

- 两个 run 是 80 列（含 20°）的历史数据；当前地形 70 列/15° 最大，20° 行只作历史对照。
- 0 kg 用无小车锚点表示，不是字面 0 kg 小车；任务口径记 NA。
- 旧口径 OK 只作追溯；任务通过仍看 `metrics.task`（JNT 0/1600）。
- 本机无 GPU，未重跑 70 列/15° 版本；结论需在训练机用新地形复核。
