## 4. 结论

- **v6 / 50 Hz / model1500 不能作为重载安全策略**：FALL 198/1400，15° 124 次，25/30 kg 约 25%。
- 与 20 Hz 同 checkpoint 相比，50 Hz 明显更差；不能只用“测试质量分布”解释（同一六档、同 0% 无载）。
- 50 Hz 下单次 fall 惩罚只有 **−1.0**（20 Hz 是 −2.5），且 checkpoint 是按训练 tracking 选的，
  不是按 fall 选的；这两点都可能放大侧翻。
- v7（13 维）如果要验证速度残差，必须先按 v7 从零训练；**不要用这个 v6 checkpoint 跑 v7 测试**。
- 当前结果支持：50 Hz 重训时需要重新标定 fall 权重/checkpoint 选择标准，并重点看 15°/25–30 kg。
