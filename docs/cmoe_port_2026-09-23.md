## Rough 任务与观察契约

`CMoE_env_cfg.py` 继承 `Imgo2RoughEnvCfg`，继续使用 PPO rough 的动作、命令和主体奖励，同时对
地形、接触奖励和终止做 CMoE 专用覆盖。5 个专家不和地形类别人工一一绑定，而由 gate 与训练目标
自行分工。

地形列占比固定为：上楼梯 15%、下楼梯 10%、boxes 15%、随机粗糙面 20%、正／反斜坡各 10%、
沟壑 20%，合计 100%。沟壑使用 Isaac Lab `MeshGapTerrainCfg`，宽度随难度从 `0.10 m` 增至
`0.16 m`；Imgo2 base 碰撞盒长度为 `0.315 m`，因此上限约为半个躯干长度。中央平台宽 `4.0 m`，
保留 reset 的 `x/y ∈ [-1, 1] m` 随机位置时，整机仍与沟边保持安全距离。

CMoE 专用奖励／终止覆盖为：

| 项目 | 当前设置 |
|---|---:|
| 足端绊脚 `feet_stumble` | `-1.0` |
| 非足端碰撞 `undesired_contacts` | `-5.0` |
| 足端踩空洞边缘 `feet_edge` | `-1.0` |
| 摆动足世界高度 `feet_height` | 关闭 |
| 足端相对机身高度 `feet_height_body` | 关闭 |
| 足端滑动 `feet_slide` | 关闭 |
| 腾空时间一致性 `feet_air_time_variance` | 关闭 |
| 对角腿镜像 `joint_mirror` | 关闭 |
| base 接触 | 立即终止，阈值 `1 N` |

`feet_edge` 不复用 actor 的 base 高度图，而是在四个足端各挂一个 `0.12 × 0.12 m`、分辨率
`0.04 m` 的向下射线网格。只有足端正在接触，且局部网格同时出现有效地面命中与 gap 的无穷远
未命中时才计罚；普通楼梯的射线都有命中，不会仅因高度不连续被当作空洞边缘。

训练 reset 保留原 PPO 的 `x/y` 位置范围和速度范围，但初始 roll/pitch 固定为 0，仅 yaw 在
`[-3.14, 3.14]` 内变化，避免机器人以倾倒姿态生成后立刻发生 base 接触。

当前观察维度为：

| 输入 | 维度 | 内容 |
|---|---:|---|
| `policy` 单帧 | 45 | 非特权本体感知，不含 base 线速度与高度扫描 |
| `policy` 历史 | 450 | 10 × 45，只对本体感知做历史堆叠 |
| `terrain` | 187 | 当前 height scanner 输出，训练时保留 `[-0.1, 0.1]` 均匀噪声 |
| actor 总输入 | 637 | 450 + 187 |
| expert／gate 输入 | 267 | 当前 45 + 显式速度 3 + 状态 latent 16 + 地形 187 + 地形 latent 16 |
| `critic` | 235 | 特权 base 线速度 3 + 本体感知 45 + 高度扫描 187 |

play 配置关闭 policy／terrain observation corruption 和域随机化，使用单环境与固定
`vx=1.0 m/s` 命令；训练配置仍沿用 rough 环境原有的噪声、随机化和命令范围。

## 与原版相比的必要适配

- 原版写死的 `45×10 + 77`、5 个专家和 12 维动作改为构造参数；Imgo2 当前仍使用 5 个专家，
  terrain 实际维度由 height scanner 配置得到 187，而不是照抄原版 77；
- critic 中显式速度标签与下一帧 proprioception 的 slice 改为配置项，当前排列为
  `[base_lin_vel(3), policy(45), height_scan(187)]`；
- Storage 移除写死的 `[527]`，使用 Runner 传入的 actor observation shape；
- rollout 结束计算 bootstrap value 前重新计算最后一帧 gate，避免沿用前一帧路由权重；
- checkpoint 同时保存两个 estimator optimizer 的状态。

## 运行入口

从 `imgo2_rl/` 目录运行；正式训练机应通过仓库 `scripts/run_isaaclab.sh` 启动对应 Python 脚本：

```bash
python scripts/rl_lab/cmoe/train.py --task=Imgo2-basemove-rough-cmoe --headless
python scripts/rl_lab/cmoe/play.py --task=Imgo2-basemove-rough-cmoe-play --num_envs=1 --headless --checkpoint="/absolute/path/to/model.pt"
```

play 的导出产物位于 checkpoint 同级 `exported/policy.pt` 和 `exported/policy.onnx`。二者输入均为
wrapper 生成的 637 维 `[10 帧 policy history, 当前 terrain]`；这不是现有 PPO／HIM-Loco 部署接口的
即插即用替代物，部署端仍需实现同样的高度扫描和历史缓存契约。
