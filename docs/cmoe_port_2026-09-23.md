# CMoE 算法移植记录（2026-09-23）

## 已落地

- 独立的 `CMoEActorCritic`、默认5专家的可配置 MoE、共享动作标准差、gate 加权 critic；
- 独立的状态 VAE 估计器和地形自编码器，保留原版估计器独立优化器；
- 原版 prototype、Sinkhorn 和 gate-terrain 对比损失；
- 独立的 `CMoEPPO`、`CMoERolloutStorage`、`CMoEOnPolicyRunner`；
- `CMoEManagerBasedRLEnv` 保留 Isaac Lab 自动 reset 前的 terminal observation；
- `CMoEVecEnvWrapper` 约定 `policy`／`terrain`／`critic` 三个 observation group，只对
  policy 做历史堆叠，输出顺序为 `[当前帧, 较旧帧..., 当前地形]`；
- 首次 reset 和单环境 episode reset 都用当前 proprioception 填满历史，避免全零启动和
  跨 episode 历史污染；
- CMoE 配置 schema、CLI 和 train 入口已独立命名，不依赖任何 `HIM*` 类；
- 新增张量级回归测试，覆盖三专家前向、gate 归一化、value、辅助损失和 Storage 维度。

## 与原版相比的必要适配

- 原版写死的 `45×10 + 77`、5 个专家和 12 维动作改为构造参数；Imgo2 默认保留原版
  5 个专家，观测维度由后续 task cfg 按实际 scanner 配置传入；
- critic 中显式速度标签与下一帧 proprioception 的 slice 改为配置项，避免绑定 G1 的
  privileged observation 排列；
- Storage 移除写死的 `[527]`，使用 Runner 传入的 actor observation shape；
- rollout 结束计算 bootstrap value 前重新计算最后一帧 gate，避免沿用前一帧路由权重；
- checkpoint 同时保存两个 estimator optimizer 的状态。
