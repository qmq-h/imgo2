# 续训练：从已有 checkpoint 接着训练

适用于同一任务、同一动作数据和兼容配置的中断恢复。**只加 `--checkpoint` 不会续训，必须同时加 `--resume`**；建议再用 `--load_run` 明确指定原运行，避免自动选到其它实验。

## 1. 找到原训练目录与 checkpoint

在服务器项目目录查看：

```bash
cd /root/Desktop/imgo2/imgo2_rl
ls logs/amp_rsl_rl/base_move_amp_height/
```

原训练目录名是这一层里的完整名称（日期时间加run_name），不是 `base_move_amp_height`，也不是本次新建的run_name。进入对应目录确认存在要恢复的 `model_4000.pt`、`model_5000.pt` 等文件。

下面命令中的 **`你的原训练目录名` 是必须替换的占位符**，不代表已确认服务器有该目录；`model_4000.pt` 也是轮号示例，应换成该目录实际存在的文件。服务器 `/root/Desktop/imgo2` 是本文统一路径示例，本轮未远端核验。

## 2. 情况一：使用系统 Python

保持原来能训练的系统Python环境，不启用Conda base。示例从4000轮再训练6000轮：

```bash
cd /root/Desktop/imgo2/imgo2_rl

IMGO2_ISAACLAB_PYTHON="$(python -c 'import sys; print(sys.executable)')" \
bash scripts/run_isaaclab.sh scripts/rl_lab/amp/train.py \
  --task=Imgo2-basemove-flat-amp-height \
  --resume \
  --load_run="你的原训练目录名" \
  --checkpoint=model_4000.pt \
  --num_envs=4096 --max_iterations=6000 --seed=1 \
  --run_name=motion_new_resume \
  --device=cuda:0 --headless
```

## 3. 情况二：使用本文的 Conda 环境

```bash
conda activate isaaclab311
cd /root/Desktop/imgo2/imgo2_rl

IMGO2_ISAACLAB_PYTHON="$CONDA_PREFIX/bin/python" \
bash scripts/run_isaaclab.sh scripts/rl_lab/amp/train.py \

  --checkpoint=model_4000.pt \
  --num_envs=4096 --max_iterations=6000 --seed=1 \
  --run_name=motion_new_resume \
  --device=cuda:0 --headless
```

## 4. 这些参数的实际含义

| 参数 | 当前 AMP 训练脚本的含义 |
|---|---|
| `--resume` | 开启恢复分支，调用runner.load；缺少它就从头训练，即使传了checkpoint |
| `--load_run` | 在 `logs/amp_rsl_rl/base_move_amp_height/` 下选择原运行目录；这里填目录名 |
| `--checkpoint` | 在所选目录中匹配checkpoint文件；这里填文件名，当前train.py不能用绝对路径代替它 |
| `--max_iterations=6000` | 本次再运行6000轮，不是总轮数上限6000 |
| `--run_name=motion_new_resume` | 本次新日志目录的后缀，不负责选择旧运行 |

轮号从checkpoint内部的 `iter` 字段恢复，不从文件名推断。若其中iter=4000，6000轮后收尾保存 `model_10000.pt`；若iter=24000，再训到30000也是传6000，而不是30000。旧版本存在过iter保存错误（AMP-08），仅看文件名不能保证起点正确。

当前AMP train.py **会创建新的时间戳日志目录**，恢复后的checkpoint写入新目录，不覆盖原运行；下次继续时应选择这个新目录。启动日志中的 `Loading model checkpoint from:` 应指向你选的旧文件，而 `Exact experiment name...`/新日志路径会显示本次新目录。

恢复内容包括actor/critic、AMP判别器、AMP归一化统计、优化器状态和轮号；仿真环境重新创建。**配置来自当前源码与本次命令，不会自动读取原run的params/env.yaml和agent.yaml来还原设置。** 续训前核对两份保存配置与当前设置，保留原来的命令覆盖；示例seed=1、4096环境也应按原运行调整。

对于这次motion_new训练中途停止：继续同一套数据和配置时用上述resume流程。原24000的xiaoji_real1使用旧动作数据，不能直接当成当前motion_new的中断恢复；更换动作数据、观测/动作接口或归一化输入尺度时，应另开新训练。修改奖励后续训属于微调实验，需单独命名并核对参数，不是原训练的无变化恢复。

# 常见错误

| 报错 | 先检查什么 |
|---|---|
| No module named imgo2_rl | 安装项目与启动训练是否使用同一个Python，是否安装到了当前仓库 |
| No module named isaacsim | 当前Python能否找到已有Sim；情况一不要误用Conda base，情况二激活isaaclab311 |
| asset path does not exist | 是否上传完整模型/网格；旧模型路径覆盖是否已清除 |
| No module named rsl_rl | 任务注册/导出仍需要兼容外部包；标准Lab2.3.2补3.1.2，不需要5 |
| CUDA out of memory | 减少num_envs，不把显存问题当成安装错误 |
