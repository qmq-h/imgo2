# 服务器训练：AMP Height

更新日期：2026-10-12。本文只说明 `Imgo2-basemove-flat-amp-height` 的安装与从头训练。

先纠正版本名称：**Isaac Sim 5.1.0、Isaac Lab 2.3.2**，不是Isaac Lab 5.1.0与Isaac Sim 2.3.2。

项目统一放在 **`/root/Desktop/imgo2`**，`/root/Desktop/` 是父目录。不要把imgo2_rl单独放在Desktop，然后把模型放进另一个imgo2目录。

```text
/root/Desktop/
├── imgo2/
│   ├── imgo2_rl/
│   │   ├── source/imgo2_rl/
│   │   ├── scripts/rl_lab/
│   │   └── datasets/imgo2_motion_new/
│   └── imgo2_description/
│       ├── urdf/imgo2_real.urdf
│       └── meshes/
└── IsaacLab/                 # 第二种情况新安装的位置
```

## 关于 RSL-RL 5：不需要升级，但还存在外部依赖

AMP的runner、AMPPPO、网络、判别器、数据加载器都在工程 `scripts/rl_lab/rl_lab/` 中，**不用再下载IsaacLab-rsl5，也不要求安装RSL-RL 5**。

但“完全不需要rsl_rl包”目前不成立：任务注册会导入 `isaaclab_rl.rsl_rl` 的配置；AMP play也使用其导出函数；该模块初始化会导入外部 `rsl_rl.env.VecEnv`。因此已有配套依赖时保持现状；全新机器安装官方Lab 2.3.2配套依赖即可。其 [官方setup.py](https://raw.githubusercontent.com/isaac-sim/IsaacLab/v2.3.2/source/isaaclab_rl/setup.py) 指定 **rsl-rl-lib==3.1.2**，不是5。本文使用TensorBoard，不另装wandb/neptune。

# 情况一：服务器已有 Isaac Sim 5.1.0 与 Isaac Lab 2.3.2

不重新安装Sim、Lab，不替换成rsl5专用分支。

## 1. 激活已有 Python 3.11 环境

以你现有环境名isaaclab311为例；若实际名称不同，只改这一处：

```bash
conda activate isaaclab311
python --version
```

应显示Python 3.11。不要使用base里的3.13。

**如果现有环境已经能启动Isaac Sim，跳过下面这一段。** 只有使用镜像 `/isaac-sim` 二进制、当前Conda找不到isaacsim时，执行：

```bash
cd /isaac-sim
source ./setup_conda_env.sh
```

这是加载已有Sim，不是重新安装。pip安装在当前环境内的Sim不需要这一段。

## 2. 放好项目并安装两个包

将当前本地完整imgo2上传到 `/root/Desktop/imgo2`，包含新数据、模型和网格。已经有完整项目就直接执行安装：

```bash
cd /root/Desktop/imgo2/imgo2_rl
unset IMGO2_URDF_PATH IMGO2_AMP_MOTION_DIR

python -m pip install -e source/imgo2_rl -e scripts/rl_lab
```

这里安装任务包imgo2_rl和工程算法包rl_lab；不安装RSL-RL 5。项目路径由代码自动推导，不需要配置多组路径。editable安装后保留源码目录。

如果服务器还没有项目，也可先clone：

```bash
cd /root/Desktop
git clone --branch xiaoji/imgo2_real https://github.com/qmq-h/imgo2.git imgo2
```

clone只包含已推送版本。**当前本地新数据、关闭滞空和速度范围如未推送，需上传这些最新文件覆盖服务器对应文件**；否则安装成功也不代表使用本次配置。已有imgo2目录不重复clone。

仅当启动报 `No module named 'rsl_rl'`、现有环境没有这个配套包时补装：

```bash
python -m pip install rsl-rl-lib==3.1.2
```

已有能运行的配套版本时不用执行，也不要为了AMP升级到5。

## 3. 冒烟测试：4环境10轮

```bash
cd /root/Desktop/imgo2/imgo2_rl

IMGO2_ISAACLAB_PYTHON="$CONDA_PREFIX/bin/python" \
bash scripts/run_isaaclab.sh scripts/rl_lab/amp/train.py \
  --task=Imgo2-basemove-flat-amp-height \
  --num_envs=4 --max_iterations=10 --seed=1 \
  --run_name=motion_new_smoke \
  --device=cuda:0 --headless
```

开头自动取当前Conda解释器，不需要手填Python路径。确认无Traceback、加载21段新数据、保存model_10.pt。当前应为：

| 设置 | 当前期望 |
|---|---|
| 训练速度 | vx±1 m/s，vy±0.4 m/s，yaw±1 rad/s |
| 滞空奖励 | `feet_air_time: null` |
| 普通任务混合比例 | `amp_task_reward_lerp: 0.3` |
| 数据 | `imgo2_rl/datasets/imgo2_motion_new/` |
| 模型 | `imgo2_description/urdf/imgo2_real.urdf` |

在终端打印的run目录里看params/env.yaml和agent.yaml确认这些值。当前流程不添加旧命令中的任务比例0.7或滞空weight100覆盖。

## 4. 正式训练：4096环境10000轮

短训练通过后，在同一终端执行：

```bash
IMGO2_ISAACLAB_PYTHON="$CONDA_PREFIX/bin/python" \
bash scripts/run_isaaclab.sh scripts/rl_lab/amp/train.py \
  --task=Imgo2-basemove-flat-amp-height \
  --num_envs=4096 --max_iterations=10000 --seed=1 \
  --run_name=xiaoji_real1_motion_new_no_air \
  --device=cuda:0 --headless
```

没有resume，表示从头训练10000轮。显存不足改2048或1024；4环境测试不保证4096显存容量。日志位于：

```text
/root/Desktop/imgo2/imgo2_rl/logs/amp_rsl_rl/base_move_amp_height/
```

默认每500轮保存checkpoint。保持原始24000运行作为对照。

# 情况二：服务器没有 Conda、Isaac Sim、Isaac Lab

采用Ubuntu 22.04/24.04 x86_64、root账号。GPU/驱动需能通过nvidia-smi；云容器的驱动/GPU挂载由平台提供，不能用pip代替驱动。

**Isaac Lab用git clone；Isaac Sim采用官方pip安装，不需要clone并编译Isaac Sim源码。** Python 3.11与Sim 5.1.0的安装方法依据 [官方pip指南](https://isaac-sim.github.io/IsaacLab/v2.3.1/source/setup/installation/pip_installation.html)。

## 1. 系统工具与 GPU 检查

```bash
apt-get update
apt-get install -y git curl ca-certificates build-essential cmake \
  libgl1 libegl1 libglib2.0-0 libx11-6 libxext6 libxi6 libxrender1 \
  libxrandr2 libxcursor1 libxinerama1 libvulkan1 vulkan-tools

nvidia-smi
```

GPU不可见先在平台处理挂载/驱动，暂不继续仿真安装。裸机没有驱动时需先安装主机驱动并重启；本流程不替云容器安装宿主驱动。

## 2. Clone 官方 Isaac Lab 2.3.2

```bash
mkdir -p /root/Desktop
cd /root/Desktop

git clone --branch v2.3.2 --depth 1 https://github.com/isaac-sim/IsaacLab.git IsaacLab
```

固定v2.3.2，避免直接clone变化中的main；保留这个源码目录。不要再创建第二份IsaacLab-rsl5。

## 3. 安装 Conda，创建 Python 3.11 环境

安装Miniforge（同样提供conda）；这是没有Conda的新机器命令，已有/root/miniforge3时不要重复覆盖：

```bash
curl -fL https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-x86_64.sh \
  -o /tmp/imgo2_miniforge.sh
bash /tmp/imgo2_miniforge.sh -b -p /root/miniforge3

source /root/miniforge3/etc/profile.d/conda.sh
conda init bash
conda create -n isaaclab311 python=3.11 pip --override-channels -c conda-forge -y
conda activate isaaclab311

python --version
python -m pip install --upgrade pip 'setuptools<82' wheel toml
```

必须在isaaclab311安装后续包，不在base安装Sim。Conda安装方式见 [Miniforge官方说明](https://github.com/conda-forge/miniforge)。

## 4. 安装 Isaac Sim 5.1.0 与 CUDA PyTorch

```bash
python -m pip install 'isaacsim[all,extscache]==5.1.0' \
  --extra-index-url https://pypi.nvidia.com

python -m pip install torch==2.7.0 torchvision==0.22.0 \
  --index-url https://download.pytorch.org/whl/cu128
```

两条都在已激活的isaaclab311执行。这个路线Sim直接安装在环境内，不需要创建_isaac_sim软链或source /isaac-sim脚本。首次使用按提示确认NVIDIA许可。无需为本流程另外安装完整CUDA Toolkit。

## 5. 安装 Isaac Lab 及配套依赖

```bash
cd /root/Desktop/IsaacLab
./isaaclab.sh -i rsl_rl
```

**这里rsl_rl表示安装Lab 2.3.2配套的3.1.2及导出依赖，不是RSL-RL 5，也不会替代工程内AMP算法。** 使用官方脚本同时安装Lab各扩展与PyTorch相关依赖；不省略isaaclab_tasks或isaaclab_rl，否则项目注册会缺模块。

检查实际环境：

```bash
python - <<'PY'
import importlib.metadata as md
import sys
import torch
print("Python:", sys.executable, sys.version)
for name in ("isaacsim", "isaaclab", "isaaclab_rl", "rsl-rl-lib"):

PY
```

Lab扩展Python包的版本号不一定等于仓库发行标签；仓库标签固定为v2.3.2。应看到Python3.11、Sim5.1.0、rsl-rl-lib3.1.2及CUDA可用。

## 6. 取得完整 imgo2 并安装

```bash

git clone --branch xiaoji/imgo2_real https://github.com/qmq-h/imgo2.git imgo2

cd /root/Desktop/imgo2/imgo2_rl
```

已有上传的完整imgo2时跳过clone，只执行cd和安装。确保本轮新数据与代码已同步；只clone未推送的旧版本不会有新设置。

检查自动解析的模型和数据：


应是本项目real URDF、存在的网格与21段motion_new数据。如果缺失，补上传完整文件，不重新安装Sim来解决模型缺失。

# 新开终端怎么办？

只需激活同一环境并进入项目：

```bash
conda activate isaaclab311
cd /root/Desktop/imgo2/imgo2_rl
```

情况二的pip安装路线不需重复安装包、不需额外Sim路径变量。情况一复用二进制镜像且未配置激活钩子时，补执行情况一的source步骤。切换仓库位置后要重新editable安装两个包。

# 常见错误

| 报错 | 先检查什么 |
|---|---|
| No module named imgo2_rl | 是否在同一Conda环境执行了两个包的editable安装，是否安装到了当前仓库 |
| No module named isaacsim | 是否激活了安装Sim的环境；二进制镜像是否加载setup_conda_env.sh |
| asset path does not exist | 是否上传完整模型/网格；旧模型路径覆盖是否已清除 |
| No module named rsl_rl | 任务注册/导出仍需要兼容外部包；标准Lab2.3.2补3.1.2，不需要5 |
| CUDA out of memory | 减少num_envs，不把显存问题当成安装错误 |
